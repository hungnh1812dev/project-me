# Storybook

Storybook 10 (`@storybook/react-vite`) for `@repo/form-commons`: one story per UI kit section plus an overview, and Playwright story tests that replace the old cms-admin UI kit page and its e2e specs. Dev and test tooling only; nothing here is exported or built into the apps.

## Feature

- Stories show the shared primitives and form components: Button, Button roles, Colour, Badge, Input, Textarea, JsonInput, Switch, Checkbox, RadioGroup, Select, DatePicker and Dialog (`Components/*`), and a "UI kit" overview that renders every section on one page under an `h1` "UI kit", each section a `region` named by its `h2`.
- Theme toolbar (`@storybook/addon-themes`): `withThemeByClassName` puts `dark` on `<html>` (light is no class), the same switch cms-admin uses. Tests set it with the `globals=theme:<light|dark>` URL parameter.
- Matches cms-admin: the same Tailwind 4, `theme.css` tokens, Fira fonts and base `body` rules, so a story renders like the control inside the app.
- Why `preview.css` copies cms-admin's base rules: the package ships no global stylesheet (fonts, `@theme inline` font vars and `@layer base` belong to each app), so Storybook needs its own copy. The app-only rules (`.rich-text`, the `main[tabindex='-1']` focus exception) are left out. Keep it in step with `apps/cms-admin/src/styles/globals.css`.
- `@storybook/addon-a11y` gives an axe panel for manual review. The automated gate is the story test in `e2e/a11y.spec.ts` (serious and critical violations only); story URLs turn the addon's auto-run off.
- Isolation: stories live only in `src/stories/`, `storybook`/`@storybook/*` imports only in `.storybook/` and `src/stories/` (guarded by `boundaries.test.ts`). Turbo `build` ignores `src/stories/**`, `.storybook/**` and `storybook-static/**`, and both apps add `@source not` for the stories, so story-only classes never reach an app bundle.

## Testing

```
pnpm --filter @repo/form-commons storybook              # http://localhost:6006
pnpm --filter @repo/form-commons build-storybook        # -> storybook-static/
PLAYWRIGHT_BROWSERS_PATH=0 pnpm --filter @repo/form-commons exec playwright install chromium   # once
PLAYWRIGHT_BROWSERS_PATH=0 pnpm --filter @repo/form-commons test:stories   # story tests on port 6007
pnpm --filter @repo/form-commons exec playwright test --list               # list the story tests
```

Story tests query by role and name, open `iframe.html?id=<id>&viewMode=story&globals=theme:<theme>`, and keep the original titles and AC tags. Storybook and the story tests are not in CI. The unit suite (`test`, `test:cov`) does not pick up `e2e/` or the stories.
