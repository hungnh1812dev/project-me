# Select

Picks one value from a short list that doesn't fit on screen as radios. A Base UI combobox: the trigger shows the choice, and the popup is a listbox.

## When to use

- One choice from about 5 to 15 known options, for example an expiry or a role.
- Use a [RadioGroup](?path=/docs/components-radiogroup--overview) instead when there are 2 to 4 options and seeing them all helps the decision.
- Use a [Switch](?path=/docs/components-switch--overview) for on/off, and an `Input` with a search for long or open-ended lists.

## Usage

```tsx
import { Field } from '@repo/form-commons/components/forms/Field';
import { Select } from '@repo/form-commons/components/ui/select';

const [expires, setExpires] = useState<string | null>(null);

<Field label="Expires in">
  <Select
    value={expires}
    onChange={setExpires}
    config={{
      placeholder: 'Choose an expiry',
      options: [
        { value: '1h', label: '1 hour' },
        { value: '1d', label: '1 day' },
      ],
    }}
  />
</Field>;
```

In a react-hook-form form, bind it with [RHFField](?path=/docs/components-rhffield--overview): `{(field) => <Select {...field} config={...} />}`.

## Guidelines

**Do**

- Put it in a `Field`, so the label names the trigger and errors are announced.
- Keep `value` as `null` until the user picks, and give a `placeholder` that says what to pick ("Choose an expiry").
- Order options logically (by size or time), not alphabetically, when they have an order.
- Keep labels short: one line, no punctuation.

**Don't**

- Don't preselect an option just to avoid the empty state when the user must make a choice.
- Don't use it for actions (that's a menu) or for navigation.
- Don't put more than one value per option or rely on colour to tell options apart.

## Accessibility and keyboard

- The trigger is a `role="combobox"` button named by the Field label; `required`, `aria-invalid` and the description reach it through `Field`.
- **Enter**, **Space** or **ArrowDown** opens the popup with the selected option highlighted. **ArrowUp** and **ArrowDown** move, **Enter** picks, **Escape** closes without a change, and focus returns to the trigger.
- Typing a letter jumps to the next option that starts with it.
