# RichTextEditor

A Tiptap editor for formatted text, with a toolbar. The value is HTML. It is a large chunk (about 400 kB), so load it with `React.lazy`.

## When to use

- Content people format: articles, descriptions with headings, lists, quotes, code and links.
- Use a [Textarea](?path=/docs/components-textarea--overview) for plain text; it is lighter and simpler.

## Usage

```tsx
import { lazy, Suspense, useId } from 'react';

import { Label } from '@repo/form-commons/components/ui/label';
import { Skeleton } from '@repo/form-commons/components/ui/skeleton';

const RichTextEditor = lazy(() => import('@repo/form-commons/components/forms/RichTextEditor'));

const id = useId();

<Label id={`${id}-label`}>Body</Label>
<Suspense fallback={<Skeleton className="h-40 w-full" />}>
  <RichTextEditor
    id={`${id}-editor`}
    labelId={`${id}-label`}
    value={html}
    onChange={setHtml}
    onBlur={() => {}}
    onRoundTripLoss={() => setLossy(true)}
    readOnly={false}
  />
</Suspense>
```

## Guidelines

**Do**

- Lazy-load it and give the fallback the editor's height, so the page doesn't jump.
- Handle `onRoundTripLoss`: it fires when the loaded HTML has markup the editor can't keep (an underline, a style). Warn that saving removes it, as the "Legacy content" example does.
- Treat an empty editor as `''`.

**Don't**

- Don't render the saved HTML elsewhere with `dangerouslySetInnerHTML` without sanitising it.
- Don't expect images, tables, underline or raw HTML; the editor only keeps paragraphs, h2 to h4, bold, italic, strike, inline code, code blocks, lists, quotes and links.

## Accessibility and keyboard

- The text is a multiline `role="textbox"` named by `labelId`; the toolbar is a `role="toolbar"` named `<label> formatting`.
- The toolbar is one Tab stop: **ArrowLeft/ArrowRight**, **Home** and **End** move between buttons. Each button has `aria-pressed` for the formatting at the cursor.
- Links accept `http`, `https` and `mailto` only. In the link box, **Enter** applies and **Escape** closes.
- The focus outline is drawn around the whole editor (toolbar and text).
