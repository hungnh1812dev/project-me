# DatePicker

Picks one day from a calendar in a popover. The trigger shows the day in the user's locale.

## When to use

- A single date: a publish date, an expiry, a filter bound.
- Use a plain [Input](?path=/docs/components-input--overview) when people know the date by heart (a birth date) and typing is faster than clicking through months.

## Usage

```tsx
import { DatePicker } from '@repo/form-commons/components/forms/DatePicker';
import { Field } from '@repo/form-commons/components/forms/Field';

const [publishOn, setPublishOn] = useState<Date | undefined>(undefined);

<Field label="Publish date">
  <DatePicker
    value={publishOn}
    onChange={setPublishOn}
    name="publishOn"
    config={{ placeholder: 'Pick a date' }}
  />
</Field>;
```

With `name`, the day is submitted as `YYYY-MM-DD` through a hidden input.

## Guidelines

**Do**

- Use `value: undefined` for "no date", and let people clear it with Clear.
- Set `config.locale` only when the page's language differs from the browser's.
- Say the allowed range in the `description` if there is one.

**Don't**

- Don't use it for a date and time together, or for a range; it picks one day.
- Don't rely on the popover to explain the format; the trigger shows the full date.

## Accessibility and keyboard

- The trigger opens the calendar with focus on the selected day (or today). Arrow keys move by day and week, **Enter** picks the day and closes it, **Escape** or Close closes it without a change.
- While open, **Tab** stays inside the calendar; focus returns to the trigger on close.
- `readOnly` shows the day but neither opens nor clears.
