# RadioGroup

One choice from a few options that are all shown at once.

## When to use

- 2 to 4 options where seeing them side by side helps: density, visibility, a plan.
- Rich options (a title, a price, a description per option): use `RadioGroupItem` children, as in [With items](?path=/story/components-radiogroup--with-items).
- Use a [Select](?path=/docs/components-select--overview) for longer lists, and a [Checkbox](?path=/docs/components-checkbox--overview) when several can be chosen.

## Usage

```tsx
import { RadioGroup } from '@repo/form-commons/components/ui/radio-group';

<RadioGroup
  aria-label="Density"
  value={density}
  onChange={setDensity}
  config={{
    orientation: 'vertical',
    options: [
      { value: 'comfortable', label: 'Comfortable' },
      { value: 'compact', label: 'Compact' },
    ],
  }}
/>;
```

Give either `config.options` or `RadioGroupItem` children, never both.

## Guidelines

**Do**

- Name the group (`aria-label`, or `aria-labelledby` pointing at a visible heading).
- Preselect the safest or most common option when there is one; leave `value` as `null` when the user must decide.
- Use `orientation: 'horizontal'` only for short labels that fit on one line.

**Don't**

- Don't use one radio on its own; that's a checkbox.
- Don't make an option trigger an action straight away; the choice applies on save.

## Accessibility and keyboard

- `role="radiogroup"` with one Tab stop. **ArrowUp/ArrowDown** (or **Left/Right**) move focus and select. **Space** selects the focused radio.
- `onBlur` fires when focus leaves the group, not between its radios.
- Each radio has a 44px hit area.
