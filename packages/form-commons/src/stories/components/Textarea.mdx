# Textarea

A multi-line text box, with an optional live character count.

## When to use

- Free text longer than one line: notes, a bio, a summary.
- Use an [Input](?path=/docs/components-input--overview) for one line, a [RichTextEditor](?path=/docs/components-richtexteditor--overview) when people need headings, lists or links, and a [JsonInput](?path=/docs/components-jsoninput--overview) for JSON.

## Usage

```tsx
import { Field } from '@repo/form-commons/components/forms/Field';
import { Textarea } from '@repo/form-commons/components/ui/textarea';

<Field label="Bio" description="Up to 120 characters.">
  <Textarea value={bio} onChange={setBio} config={{ rows: 4, maxLength: 120 }} />
</Field>;
```

## Guidelines

**Do**

- Size `rows` to the expected answer, so people see most of what they write.
- Set `maxLength` when there is a real limit: the "n / max" count shows under the box and turns to the warning colour at 90%.
- Say the limit in the `description` too, so it is known before typing.

**Don't**

- Don't use it for structured data (lists of values, JSON); give each value its own control.
- Don't rely on the count colour alone to warn; the count text is always there.

## Accessibility and keyboard

- `Field` provides the label, description and error wiring.
- **Enter** adds a line; it never submits the form. **Tab** leaves the box.
