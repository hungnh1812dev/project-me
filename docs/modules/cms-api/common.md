# Common (cms-api)

## Purpose

Cross-cutting building blocks every cms-api module uses: the unified error response, request id and security headers, throttling, client IP, time and shared validation schemas.

## Techniques

One global exception filter shapes every error. A 401/403 on an unfinished multipart upload closes the socket after the answer (`closeAfterAnswer`), so a slow body cannot hold a connection.

## Technologies

NestJS 11, Express.

## Entry points

Imported by feature modules; wired in `App.setup.ts`.

## Where to change what

New error kind: `DescribeHttpException.rules.ts`. New shared limit or header: the matching `constants/` file.
