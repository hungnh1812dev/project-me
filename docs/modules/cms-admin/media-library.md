# File Library page (cms-admin)

## Purpose

The File Library for accounts with `media` permissions: a searchable, filterable grid of uploaded files with upload, replace in place, alt-text edit and delete (SPEC §15.3).

## Techniques

Server state through the media feature (`Media.api`, `Media.queries`, `MediaApi.context`); filters and grid from `features/media`; actions shown by caller permissions (`useCallerAccess`); focus restored after dialogs (`useRestoreFocus`); paging with `Pagination`.

## Technologies

React 19, TanStack Query (`@tanstack/react-query`), react-hook-form + zod where there is a form, `@abyss/form-commons` components; text from `configs/Copy.constants.ts`.

## Entry points

Route `APP_ROUTES.MEDIA` (`/media`); menu item from the views registry, shown for the `media` subject.

## Where to change what

The route is in `configs/App.routes.ts` and the page is registered in `views/Views.registry.ts`. Text goes in `configs/Copy.constants.ts`, never inline. A component a second page needs moves to `features/` or `components/` (code-standards §4.6). Grid, filters, upload and picker live in `features/media`; this folder holds only the page and its dialogs.
