# Login page (cms-admin)

## Purpose

Signs a user in with email and password, then runs the two-factor step (TOTP or email code) when the account needs it. Shows notices (signed out, session ended) and links to owner setup only while setup is open.

## Techniques

Auth state from `Auth.slice` and `Session.context`; mutations through `Auth.api`; login errors mapped by `Login.errors`, notices by `LoginNotice.rules`. The two-factor modal holds a short-lived temp token; a dead token ends the step.

## Technologies

React 19, TanStack Query (`@tanstack/react-query`), react-hook-form + zod where there is a form, `@abyss/form-commons` components; text from `configs/Copy.constants.ts`.

## Entry points

Route `APP_ROUTES.LOGIN` (`/login`); `ProtectedRoute` sends signed-out users here.

## Where to change what

The route is in `configs/App.routes.ts` and the page is registered in `views/Views.registry.ts`. Text goes in `configs/Copy.constants.ts`, never inline. A component a second page needs moves to `features/` or `components/` (code-standards §4.6). Auth rules live in `features/auth` (high-risk path: security review before commit).
