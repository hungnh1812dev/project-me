# Media feature (cms-admin)

## Purpose

The media pieces shared by the File Library page and the document editor: the media API client and query, the upload dialog with a parallel upload queue and progress, the grid and filters, the picker dialog, the `MediaField` form field and the image insert dialog for richtext (SPEC §15.2, §15.3, §15.6).

## Techniques

Upload queue as pure rules (`UploadQueue.rules.ts`: file checks by kind and size, state transitions, totals) driven by `useUploadQueue` with a parallel limit; the library refreshes when a batch settles. Allowed MIME types and size limits per kind in `Media.constants.ts`. API errors mapped by `toMediaError`. Actions shown by caller permissions (`MEDIA_SUBJECT`).

## Technologies

React 19, TanStack Query, react-hook-form (`useController`), axios, `@abyss/form-commons` (`MediaInput`, `MediaPreview`, `MediaDetails`), `lucide-react`.

## Entry points

`index.ts` exports `MediaField`, `UploadDialog`, `ImageInsertDialog`, `mediaToForm`/`mediaToApi`, `MEDIA_SUBJECT`; `Media.feature.ts` registers the feature; `views/media-library` uses the grid and filters.

## Where to change what

A new allowed file kind or limit: `Media.constants.ts` (and the cms-api media rules; the shared constants contract checks both). A new media API call: `Media.api.ts` + `Media.queries.ts`.
