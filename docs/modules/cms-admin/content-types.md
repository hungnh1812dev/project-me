# Content types (cms-admin)

## Purpose

Reads the content type catalog (`ContentType`: slug, `displayName`, kind, draft and publish flag, fields) that the content menu, list and edit pages build on.

## Techniques

One axios call; `displayName` is the only name shown to people, the slug stays in routes and API calls.

## Technologies

axios (through the shared API client).

## Entry points

`index.ts` exports `getContentTypes`, `ContentType`, `ContentTypeField`; `contentTypesFeature` registers the service.

## Where to change what

A new key in the content type view: add it to `ContentType` in `ContentTypes.api.ts` (additive).
