# API contract (v1 outline)

Part of the [project spec](../../../SPEC.md). Reference: definitions and values only; the rules that use them are in the `RULES.md` files.

All routes sit under `/api/v1`, except the health routes at the server root (cms-api API-3). One error shape: `{ statusCode, errorCode, message, details?, requestId }`.

Human check (D25): the bodies of `POST /auth/login`, `/auth/2fa/verify`, `/auth/2fa/email-challenge`, `/setup/owner`, `/auth/password/request-otp` and `/auth/password/reset` also carry `turnstileToken` (string, 1 to 2048 characters, required). A refusal answers `400 HUMAN_CHECK_FAILED` (token missing, too long, failed, used, or for another form) or `503 HUMAN_CHECK_UNAVAILABLE` (verifier not configured or unreachable); form ids, field and codes are in `content/public-constants.json`.

| Area                   | Endpoints                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Health                 | `GET /health`, `GET /health/live`, `GET /health/ready` (server root, not under `/api/v1`; API-3). `/health` is the public path; `/health/live` and `/health/ready` are in-cluster only, Traefik answers them 403 from outside (global RULES "Health routes" rule 4). web and cms-admin serve the same three paths on their own servers (PS-8, ADM-12)                                                                                                                      |
| Auth                   | `POST /auth/login` (`{ email, password, rememberMe? }`, §16) → `{ accessToken }` or `{ requires2FA, tempToken, methods }` · `POST /auth/2fa/verify` · `POST /auth/2fa/email-challenge` · `POST /auth/refresh` (cookie) · `POST /auth/logout` (cookie) · `GET /auth/me`                                                                                                                                                                                                     |
| 2FA setup              | `POST /auth/2fa/totp/setup` · `POST /auth/2fa/enable` · `POST /auth/2fa/disable` (password + code)                                                                                                                                                                                                                                                                                                                                                                         |
| Password               | `POST /auth/password/request-otp` (always 202) · `POST /auth/password/reset` · `POST /auth/password/set` (invite) · `POST /auth/password/change`                                                                                                                                                                                                                                                                                                                           |
| Accounts               | `GET /accounts?page=&pageSize=` (`{ data, meta { page, pageSize, total } }`) · `POST /accounts` (invite) · `PATCH /accounts/:id` · `POST /accounts/:id/disable` · `POST /accounts/:id/enable` · `POST /accounts/:id/invite/resend` · `POST /accounts/:id/sessions/revoke`                                                                                                                                                                                                  |
| Roles                  | `GET/POST /roles` · `PATCH/DELETE /roles/:id` · `PUT /roles/:id/permissions`                                                                                                                                                                                                                                                                                                                                                                                               |
| API tokens             | `GET/POST /api-tokens` · `PATCH /api-tokens/:id` · `POST /api-tokens/:id/revoke`                                                                                                                                                                                                                                                                                                                                                                                           |
| Content types          | `GET /content-types` (filtered to subjects the actor can read) · `GET /content-types/:slug` · `POST /content-types/validate` (owner only, `{ definition, mode }` answers `{ valid, errors }`, SB-10) · field view keys add `width` (non-component content fields; default `full`) and `displayName` (only when set) and `options` (`enumeration` fields only)                                                                                                              |
| Documents              | `GET /documents/:slug` (`status=draft\|published`, filter/sort/page; a link-only type answers read-only actors `403 DOCUMENT_LIST_NOT_ALLOWED`, CM-13) · `GET /documents/:slug/:documentId` · `POST /documents/:slug` · `PUT /documents/:slug/:documentId` (`version`) → `409 DOCUMENT_VERSION_CONFLICT { currentVersion, server, submitted, diff }` (masked) · `POST …/:documentId/publish` (`expectedVersion`) · `POST …/:documentId/unpublish` · `DELETE …/:documentId` |
| Bulk (collection only) | `POST /documents/:slug/bulk/create` · `/bulk/publish` · `/bulk/unpublish` · `/bulk/delete`, each `{ atomic, items }` → per-item results                                                                                                                                                                                                                                                                                                                                    |
| Presence               | `POST /documents/:slug/:documentId/presence` → active editors                                                                                                                                                                                                                                                                                                                                                                                                              |
| Media                  | `POST /media` (multipart) · `GET /media` · `PATCH /media/:id` (alt) · `DELETE /media/:id`                                                                                                                                                                                                                                                                                                                                                                                  |
| Reviewer               | `GET /reviewer/status` · `POST /reviewer/sessions` (Turnstile) · `GET /reviewer/sessions` (owner) · `PUT /reviewer/settings` (owner) · all four answer `404 REVIEWER_FEATURE_OFF` while `REVIEWER_FEATURE_ENABLED` is not `true` (D2a)                                                                                                                                                                                                                                     |
| Audit                  | `GET /audit-logs` (owner)                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Backups (D20)          | `GET /backups` (owner) → `{ data: [{ key, kind, fileName, createdAt, sizeBytes }], meta: { count, totalBytes, latestAt, isStale } }` · `POST /backups/download-links` (owner, `{ key, password, code }`) → `201 { url, fileName, expiresAt }`; `404 BACKUPS_NOT_CONFIGURED` while the storage keys are unset                                                                                                                                                               |
| Owner setup (D1)       | `GET /setup/status` → `{ open }` · `POST /setup/owner` (setup token in body) → `201 { email }`; `404` once an owner exists or when no token is configured                                                                                                                                                                                                                                                                                                                  |
| GraphQL (D18)          | `POST /graphql` (queries only): per content type `<type>(documentId, status)` and, for collections, `<type>List(status, page, pageSize, sort, filter)` → `{ data, meta }`; same auth, masking and error codes as the document reads                                                                                                                                                                                                                                        |

`:slug` is always checked against the `content_types` registry before any SQL is built; never interpolated directly.

**Web BFF (D21, [ADR 0018](../../adr/0018-web-bff.md) §2, error codes §3).** Served by apps/web on the web origin under `/api/v1`; the only API the public site's browser calls. JSON only, `Cache-Control: no-store`, errors `{ statusCode, errorCode, message }`.

| Endpoint                                  | Body                                                          | Answer                                                                                                                                                                          |
| ----------------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /api/v1/health`                      | -                                                             | `200 { status: "ok" }` · `503 { status: "unavailable" }`                                                                                                                        |
| `GET /api/v1/session`                     | -                                                             | `200 { user: { id, email, displayName, role } \| null }`                                                                                                                        |
| `POST /api/v1/auth/login`                 | `{ email, password, turnstileToken, rememberMe? }` (§16 RM-6) | `200 { status: "signed-in", user }` · `200 { status: "two-factor-required", methods }`                                                                                          |
| `POST /api/v1/auth/two-factor/email-code` | `{ turnstileToken }`                                          | `202`                                                                                                                                                                           |
| `POST /api/v1/auth/two-factor/verify`     | `{ code, turnstileToken }`                                    | `200 { user }`                                                                                                                                                                  |
| `POST /api/v1/auth/logout`                | -                                                             | `204`                                                                                                                                                                           |
| `GET /api/v1/cv/{documentId}`             | -                                                             | `200 <CV page data>` for the signed-in visitor (`401 BFF_SESSION_REQUIRED` without a session; `404 BFF_NOT_FOUND` for a malformed, unknown or unpublished id; public-site PS-5) |
