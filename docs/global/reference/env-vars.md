# Environment variables

Part of the [project spec](../../../SPEC.md). Reference: definitions and values only; the rules that use them are in the `RULES.md` files. Sources: each app's `.env.example`, `apps/cms-api/src/config/Env.schema.ts` and `Config.constants.ts`, `apps/web/src/configs/Server.env.ts`.

**Required:** `yes` = the app does not start (or build) without it · `prod` = required only when `NODE_ENV` / `APP_ENV` is `production` · `if <condition>` = required when another key has that value · `no` = optional.
**Scope:** `runtime` = read by the server at start · `build` = baked into the bundle at build · `dev` = dev server only · `test` = test stacks (dev, smoke, e2e) only · `CLI` = scripts only.
