Tech stack

AreaChoice
Monorepopnpm 11 workspaces + Turborepo 2, Node ≥ 24
APINestJS 11 on Express, TypeScript strict
Core persistencePrisma 7 (schema public) via @prisma/adapter-pg
Content persistenceGenerated SQL migrations in schema content, queries through Kysely
Authpassport-jwt (HS256 pinned), argon2 (Argon2id), otplib (TOTP)
GraphQLgraphql-js with an in-house handler, no Apollo / Yoga
AdminReact 19 + Vite SPA on nginx, Redux Toolkit (session/UI), TanStack Query, Axios, REST
WebNext.js 16 App Router, standalone, Server Components, GraphQL server reads, Tailwind v4
UI kit@abyss/form-commons: shadcn/ui + Tailwind, react-hook-form + Zod, Tiptap, CodeMirror 6
MediaCloudinary, sharp re-encoding, file-type magic bytes
Bot protectionCloudflare Turnstile (server-side verify)
TestsJest + Supertest + Testcontainers (API), Vitest + Testing Library (UI), Playwright (e2e)
