Core schema public (Prisma)

Every table has id, created_at, updated_at; user-facing tables also have a UUIDv7 document_id. created_by / updated_by reference accounts with ON DELETE SET NULL. A partial unique index allows exactly one live owner (D1). Source: apps/cms-api/prisma/schema.prisma.

Main columns only.

Content schema content (generated, Kysely)

Generated from content/schemas/*.json. A root table per type with version and published_at: at most one draft (published_at IS NULL) and one published row per document_id (partial unique indexes, D11). Components are tables <slug>__<path> (max depth 3) owned by their parent with ON DELETE CASCADE; no link tables. The registry lives in content._content_types, applied migrations in content._migrations.

cv-page produces 8 tables (root + 7 component tables); profile is a collection with a media field.

Conditions DSL (ABAC)

{ "all": [ { "field": "createdBy", "op": "eq", "value": "$actor.id" },
           { "field": "<readable field>", "op": "in", "value": [..] } ] }

Operators eq, ne, in; variables $actor.id, $actor.roleRank. Anything else is rejected when the permission is saved; conditions compile to parameterized SQL only.
