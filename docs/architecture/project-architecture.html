Abyss project architecture

Master page. Start here for the big picture, then open the topic pages on the left.

What it is

A headless CMS (cms-api + cms-admin) that serves CV / portfolio content defined by JSON schemas, plus the public site (web). It showcases RBAC + field-level masking, draft / publish with optimistic concurrency, an always-on security audit and a read-only reviewer mode.

Architectures in use

  • Monorepo: pnpm workspaces + Turborepo
  • cms-api: modular monolith, clean architecture (ports & adapters) per module, guarded by architecture tests
  • CQRS-style split in documents (command / query services)
  • cms-admin: feature-sliced SPA with a feature registry
  • web: Next.js App Router, Server Components, GraphQL reads
  • Deploy: containers on K3s + Traefik, GitOps image bump
